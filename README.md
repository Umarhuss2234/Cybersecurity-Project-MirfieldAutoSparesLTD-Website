# Cybersecurity Project - Mirfield Automotive Spares Ltd Website

## Project Overview

This repository documents the cybersecurity work I carried out on the website of **Mirfield Automotive Spares Ltd**, a local scrapyard and commercial vehicle breakers business. This is my first cyber security project i have done, therefor 

My main responsibility was to improve the website's security, protect sensitive information, create backups, and perform security testing to identify potential vulnerabilities.

**Website:** [Mirfield Automotive Spares Ltd](https://mirfieldautospares.co.uk/)

## Repository Information

This repository does not contain the website's source code, database, credentials, configuration files, or any sensitive materials used during the project.

I have chosen not to make these resources publicly available to protect the business's information, maintain confidentiality, and follow cybersecurity best practices and applicable data protection requirements, including the UK GDPR and Data Protection Act 2018.

Instead, this repository provides an overview of the security improvements, procedures, and testing I carried out.

---

## Security Improvements and Procedures (What I Did)

During this project, I focused on 10 key areas to improve the website's overall security.

### 1. Website and Database Backups

- Created a full backup of the website files and database.
- Stored an additional backup securely outside the hosting environment.
- Verified the integrity of the backups and tested the restoration process to ensure the website could be recovered if necessary.

### 2. Administrator Account Security

- Strengthened administrator accounts by implementing unique, strong passwords.
- Enabled multi-factor authentication (MFA) where supported.
- Reviewed existing administrator accounts and removed unnecessary or unused access.
- Applied the principle of least privilege to reduce the risk of unauthorised access.

### 3. Software and Dependency Updates

- Reviewed the website's content management system (CMS), plugins, themes, and dependencies.
- Identified outdated software and applied available security updates.
- Checked that the website's software and hosting environment were running supported versions where possible.

### 4. HTTPS and TLS Security

- Checked the website's SSL/TLS certificate to ensure encrypted connections were supported.
- Verified that HTTP traffic was correctly redirected to HTTPS.
- Checked for mixed-content issues that could weaken secure connections.

### 5. Web Application Firewall (WAF)

- Reviewed the website's firewall protection.
- Configured web application firewall rules where supported by the hosting environment.
- Improved protection against common web-based threats and malicious requests.

### 6. Administrator Login Protection

- Strengthened security around administrator login pages.
- Reviewed login rate limiting and protection against repeated authentication attempts.
- Enabled or configured login activity monitoring where supported.

### 7. Server and File Permissions

- Reviewed website file and directory permissions.
- Applied the principle of least privilege to restrict unnecessary access.
- Checked that sensitive configuration files and credentials were appropriately protected.
- Reviewed unnecessary services and access methods where possible.

### 8. Customer and Business Data Protection

- Reviewed how the website handled and stored customer and business information.
- Checked database access permissions and relevant encryption controls.
- Considered data retention, confidentiality, and access restrictions.
- Focused on reducing the risk of unauthorised access to sensitive information.

### 9. Security Monitoring and Logging

- Reviewed available server and website security logs.
- Checked administrator login activity and other relevant security events.
- Configured available monitoring and alerting features to help identify suspicious activity.

### 10. Security Testing and Vulnerability Assessment

- Performed authorised security checks within the agreed scope of the project.
- Reviewed the website's configuration for potential security weaknesses.
- Identified areas requiring improvements and applied appropriate mitigations where possible.
- Checked the website's functionality after making security changes to reduce the risk of disrupting normal operations.

## Project Scope and Clarification

**I did not develop or build the Mirfield Automotive Spares Ltd website. My involvement was focused on securing and maintaining the existing website.**

The website was originally developed several years ago, and its design and overall appearance reflect its age.

Although I have some experience with HTML, CSS, JavaScript, and software development, redesigning or rebuilding the website was not part of my responsibilities.

My task was specifically to improve the security of the existing website, rather than modify its frontend design or develop new functionality.

This project allowed me to apply my cybersecurity knowledge in a real business environment and gain practical experience working with website hosting, security configurations, access controls, backups, and vulnerability management.
